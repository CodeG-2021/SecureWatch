# SecureWatch Web

Web frontend for analysts, administrators, and supervisors.

Recommended stack from the requirements:

- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Zustand o Context API
- SSE or WebSockets for real-time progress.

Initial responsibilities:

- User registration and sign-in.
- Case management.
- Manual evidence upload.
- Dashboard for states, tasks, workers, and findings.
- Report viewing and download.
